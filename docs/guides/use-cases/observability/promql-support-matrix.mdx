This page lists the PromQL functions and aggregation operators exercised by the recorded Prometheus compliance suite. The native ClickHouse PromQL converter is used by the Prometheus HTTP query API, the `promql` dialect, and the [`prometheusQuery`](/sql-reference/table-functions/prometheusQuery) and [`prometheusQueryRange`](/sql-reference/table-functions/prometheusQueryRange) table functions.

## Status definitions {#status-definitions}

| Status | Meaning |
|---|---|
| Supported | The native converter has an implementation for the feature. |
| Partial | The native converter has an implementation with the limitation stated in the Notes column. |
| Not supported | The native converter does not have an implementation for the feature. |

The Compliance query outcomes column summarizes the Prometheus PromQL compliance suite. Counts represent complete queries, not isolated function tests. Passing queries are attributed to every cataloged function or aggregation operator in the query. An unsupported result is attributed only to the function or aggregation operator named in the ClickHouse exception. Other failed queries are recorded as differences for every cataloged feature in the query.

Compliance results measure the queries covered by the suite. They do not prove that every input or combination is supported. Functions and aggregation operators that are not exercised by the recorded suite are omitted.
