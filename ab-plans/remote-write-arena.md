## Method
- Per case: `CH=<A binary> PORTS="9001 9002" NAMES="A B" DATA=<dir> ROUNDS=15 REQUESTS=50 WARMUP=30 <case env> python3 ab/run.py > ab/<case>-<date>.jsonl`, then `python3 ab/summarize.py ab/<case>-<date>.jsonl`. The servers get the same requests (same timestamps per round), in an order that rotates per round; CPU is utime + stime of the server process from `/proc/<pid>/stat` around each batch, with a 1.5 s pause for the last async insert.
- One A/A pass first (`T1` env, both servers on A's binary, `ROUNDS=8`) for the noise figure.
- If you can, also capture one CPU profile per server during T1 (start the servers with `PROFILE_EXTRA='<query_profiler_cpu_time_period_ns>2000000</query_profiler_cpu_time_period_ns><query_profiler_real_time_period_ns>0</query_profiler_real_time_period_ns>'`), so I can check that the parse and destroy stacks shrank as predicted.

## Metrics
- CPU µs per sample (median and min–max over the rounds) per server; request latency from `rw.py` is not a target (it is dominated by the async insert wait).

## Correctness
- `ab/summarize.py` prints the hashes of the tags table (`sum(cityHash64(id, metric_name, tags))` over distinct rows) and of the samples table (`sum(cityHash64(id, bucket, samples))` and `sum(length(samples))` with `FINAL`) of each server; they must be equal (checked as A/A on master: equal, 100,000 samples).
- `tests/integration/test_prometheus_protocols/test_write_read.py`, `test_query_api.py` and `test_evaluation.py` pass on B (they send remote-write requests).

## Pass / fail
- **Pass:** T1 at least −7% (median), T2 at least T1's change minus the A/A spread, E1 not slower; hashes equal; the integration tests pass.
- **Fail, T1 under 7%:** the allocator is cheaper on that host than here (jemalloc thread caches), or the arena's own blocks cost more; I lower the claim to what was measured, or withdraw the branch if it is under 5%.
- **Fail, E1 slower:** the arena plus heap string buffers costs more than the heap alone; I'd look at `ArenaOptions` (block sizes) before anything else.
