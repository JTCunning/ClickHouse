## Upstream
Merged (comp-promql):
- https://github.com/ClickHouse/ClickHouse/pull/128764 (2026-11-03): the "adaptive aggregator" is switched off for SQL generated from PromQL. It trades a possible plan switch for predictable timings, so range queries stop varying between runs.

## Review bot
Two changes to what the bot checks:
- 2026-11-04: new check "New form of an existing output". When a change makes a component produce output in a form it did not before, the bot lists every consumer of that output, treats any use before the conversion point as a finding, rates a recurring class as at least a Major and wants tests that reach each consumer's form-specific code. For my work: when a fix changes the shape of intermediate state (grid state layout, selector id set), the PR text must list all consumers.
